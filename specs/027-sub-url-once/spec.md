# Spec 027 — Ссылка подписки: один ввод в десктопе, наследование в игре (flow-track)

## Требование владельца
- Никаких захардкоженных ссылок провайдера в коде/релизе.
- Ввод один раз (десктоп) → игровой режим подхватывает сам.
- Десктоп и QAM — одно приложение с точки зрения пользователя.

## Решение
- `save_sub_url()` (валидация http(s), атомарная запись через tmp+rename)
  + editable QLineEdit + «Сохранить ссылку» в Settings/SUBSCRIPTION.
- Единый источник: `~/AI/neodon-sub/neodon-sub.py` (`URL='…'`).
  Десктоп пишет, decky `refresh_sub` читает тот же файл тем же regex.
- Релиз-сейфти: инсталлер ссылку не поставляет; без URL оба конца
  показывают «URL подписки не найден» + плейсхолдер.
