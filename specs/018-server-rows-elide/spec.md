# Spec 018 — строки серверов DPI-честно + гонка за живой файл (flow-track)

## Жалоба
Текст серверов (PL/NO/SE) «съезжает в пизду»: обрезка слева, налезание строк.

## Диагноз (пиксели + геометрия)
- Оффскрин-геометрия здорова (299px, HBAR 0) — баг виден только вживую.
- Причины: теги `[RU2]/[RU3]` не матчили `{2}` (префикс выживал и рвал
  строку); лимит 24 символа слеп к DPI/масштабу шрифта handheld.
- Фикс: strip `{2,4}` alnum; `_ElidedLabel` (ручная отрисовка через
  fontMetrics — у QLabel нет setElideMode); truncation данных удалён.
- Живой пруф: кроп серверов — оба столбца, флаги, имена, дески, «—» пинга,
  активная зелёная. Налезаний/обрезок нет.

## Гонка (важно)
- Параллельная сессия пишет тот же живой файл: был краш на ровном месте
  (`setElideMode` в чужой версии), процесс лежал. Вылечено: их файл =
  мой побайтово (diff 0 строк), GUI поднят на нём, в журнале чисто.
- Правило: перед рестартом сверять md5 проект/лайв; чужую версию сохранять
  в сторону до разбора, а не затирать.
