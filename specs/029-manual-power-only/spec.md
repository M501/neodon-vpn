# Spec 029 — Только ручное включение везде (flow-track)

## Требование владельца
- Никаких автоподключений: ни при старте (десктоп/игра), ни при входе
  в плагин, ни при выборе сервера. Вкл/выкл — только главная кнопка.
- Два VPN одновременно исключены стопроцентно.

## Факты аудита
- Юниты уже disabled (42); таймеров/автостартов нет; watchdog только при
  desired != off; десктоп при старте toggle не зовёт; decky switchServer
  и так только stage'ил (set_server при неактивных сервисах не стартует —
  проверено чтением скрипта, ветки только restart активных).
- НАЙДЕНО: десктоп `_start_server_worker` делал
  `start_after = state != CONNECTED` — авоконнект при выборе. Вырезано:
  всегда False + комментарий-предупреждение.
- Два VPN невозможны конструктивно: один sing-box unit, один TUN,
  один MODE_FILE, flock single-flight. Живой пруф: `pgrep -c = 1`
  при CONNECTED.

## Переход десктоп→игра
- Состояние общее (тот же бэкенд): оставленный включённым в десктопе VPN
  виден в QAM как включённый — это ТОТ ЖЕ vpn, не второй. Авто-выключения
  при смене сессии нет сознательно (приказ «только я нажимаю»);
  гасится одной кнопкой в любом из концов.
