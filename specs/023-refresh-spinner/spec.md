# Spec 023 — спиннер обновления (flow-track)

## Заказ
Кнопка ↻ рядом с Пинг: синяя подсветка + вращение стрелки + докрутка в ноль.

## Реализация (воронка refresh_sub)
- `_spin_start`: синяя рамка обеим кнопкам, базовый синий pixmap, QTimer 50мс.
- `_spin_tick`: +15°, рендер из базового (без деградации), иконка кнопки.
- `_spin_stop` → фаза settle (25мс) → `_spin_finish` в ноль: базовая иконка,
  снятие рамок, enable. Худший докрут 24 тика ≈ 0.6с, математически сходится
  всегда (шаг делит 360).
- Хук `refresh` для QA-запуска без тапов.

## Пруфы
- Unit: вращение (угол растёт), settle из 105° ≤24 тиков в ноль, glow on/off,
  enable/disable оба исхода.
- Пиксель: оффскрин-рендер зависшего спиннера — синяя рамка + стрелка под
  углом (живьём fetch быстрее скрина, честно зафиксировано).
- 49/49 pytest; деплой + рестарт.
