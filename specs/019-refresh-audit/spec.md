# Spec 019 — отдача обновления + аудит десктопа (flow-track)

## Фикс
Кнопки обновления (иконка + «Обновить подписку») гаснут + «Обновление…»
на время fetch, возвращаются в обоих исходах (`_refresh_restore`).
Тест: disabled → enabled ok/fail.

## Аудит десктопа (честный, 2026-09-09)
DONE (всё с живыми пруфами): паритет proxy (аудит+live+A/B 88 ячеек),
свитчи 2–4с, no-flip, тишина нотифаев, гистерезис+журнал, settle питания,
очередь намерений, таб (иконки/диалог/канарейки), киллсвитч (доказан,
DNS-сука), трей-флаг+режим (пиксели), пинг in-place, ярлык→окно,
single-instance, подписка (поле + refresh квота+серверы), .desktop.
OPEN: чекбокс автостарта мёртв (UI без backend — wire или снести);
менеджер подписок (add/clipboard/QR/delete/export — большой спек);
упаковка/дистрибуция (ресёрч R1+R2 летит); Game Mode (после упаковки).
