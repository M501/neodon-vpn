# Spec 001 — Neodon GUI: отзывчивость и состояния (flow-track)

> Источник: жалобы владельца (тач мёртвый, свитчи неохотно, таймер отдельно, реконнекты, пустая подписка, трей) + трек B (готов) + трек C (готов) + трек A (частично: Hiddify/v2RayTun default=system-proxy).

## Проблема
GUI опрашивает бэкенд каждые 4с командой с потолком 10с через общий flock — очередь воркеров растёт, toggle ждёт за ней. Тач глотает тапы (двойные QScroller-жесты). Нет единого set_state: таймер/трей/кнопки живут отдельно. Подписка молча N/A. Смена сервера = до 65с потолков при реальных 0.45с работы.

## Scope (ТОЛЬКО neodon-vpn.py + tests/, 1 файл + тесты)
IN: single-flight poll + flock -n + интервал 8с; fast-path status (лёгкий JSON) + тяжёлый опрос 60с отдельно; set_state() единый (таймер/трей/кнопки); QScroller один хелпер Touch-only; SelectWorker разбить на фазы с прогрессом + потолки 10/12с; подписка: кэш + причина N/A + фон 30мин; трей-иконки off/on/wait + тултип; чистка _workers; удалить дублирующий fetch_exit_ip.
OUT (не трогать): бэкенд-скрипты, профили, DNS, сервер по умолчанию, Game Mode, визуальный редизайн.

## Верификация (Iron Law)
- `QT_QPA_PLATFORM=offscreen pytest tests/` — зелёные (state machine, single-flight, sub-парс, QScroller-хелпер наличие/параметры).
- `python -m py_compile`, `bash -n` затронутых .sh (нет).
- Live (хост, по команде владельца или в окно простоя): висящих status-json >1 нет (`ps`), свитч сервера <3с по логу, тап/флик по записи GSR.
- `audit_parity.py` повторно — правила не задеты (регресс-контроль).
- Честный итог: DONE / WITH CAVEATS / BLOCKED с пруфами из тулов.

## Вердикт ресёрча (сжато)
- B: интервалы/очередь/тач/трей/подписка/атрибуция — принято целиком (8 пунктов, P0→P3).
- C: pytest-qt+offscreen (внедряем), pyatspi-инспекции, GSR+portal-restore для motion-QA (по требованию), visual-verdict JSON как формат вердикта, taste применим ~20%.
- A (частично): Hiddify desktop default=systemProxy; v2RayTun win vpn_mode=proxy. Наш SMART-по-умолчанию — outlier индустрии. Решение: дефолт не меняем в этом спеке (риск, привычка), но PROXY доводим до паритета и замеряем; смена дефолта — отдельный спек по данным замеров.
