# Spec 016 — трей-флаг, пинг без дёрганья, ярлык показывает окно (flow-track)

## Заказы владельца
1. Трей: флаг страны сервера + режим (proxy/tunnel), обычный значок когда off.
2. Баги: пинг разваливает список серверов; случайные reconnecting; ярлык
   должен показывать окно, а не молча выходить (single-instance есть).

## Что сделано
- `_sync_tray`: CONNECTED → иконка = флаг активного сервера (22×15, fallback
  на темные иконки), тултип `ON · PROXY/TUNNEL · сервер`. Остальные PID `00:09` states unchanged.
- Пинг: latency вынесена в фиксированный QLabel 64px, результаты красятся
  in-place (`_on_ping_result`), `_ping_done` больше не перестраивает сетку.
- Ярлык: второй экземпляр пишет ACTION_HOOK, `tick()` (1с) показывает окно.
  .desktop уже стоит (applications + Desktop).
- Проба exit: retry внутри status-json (пачки DEGRADED 4×/7мин при ротации
  egress). Steady-цена ноль (retry только после провала).

## Не сделано (честно, следующим спеком)
- Менеджер подписок (добавить/удалить/QR/файл) — большой фича-спек, не в этом.
- Кнопка обновления подписки УЖЕ есть (иконка ↻ + «Обновить подписку»):
  `_sub_loaded_full` обновляет квоту И перезагружает серверы.
