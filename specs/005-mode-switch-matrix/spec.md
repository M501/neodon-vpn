# Spec 005 — режимы: флип подсветки + медленный туннель (flow-track)

## Жалобы
1. full→smart: подсветка сначала PROXY, потом обратно TUNNEL («будто ничего не было»).
2. Вход/выход из туннеля невероятно долгие (toggle full 14с).

## Корни (замеры хоста)
1. Флип: каждый опрос дёргал `set_mode(desired)` безусловно; пока тумблер
   гасит туннель (~1с), опросы читают старый .mode → подсветка возвращается.
   Фикс GUI: пропуск re-highlight пока `_op_in_progress` (тест есть).
2. 14с входа: ks-install 9.4с (~20-40 правил по одному через sudo) + sleep 2 +
   грубый цикл + холодный exit. Фикс: allows persist (динамичен только REJECT,
   2 вызова), LOCKED = наличие REJECT (не счётчик), терпеливая проба в переходе
   (маркер → -m 5), фоновый прогрев, tun-poll вместо sleep 2, цикл 0.2с.
3. По пути найдены и закрыты: DNS-дыра (ALLOW на весь 1.1.1.1 → только dport 53
   + миграция), unbounded-рост endpoint-IP (prune stale), deadlock маркера
   (кандидат → оверрайд). Киллсвитч доказан рабочим: 551+ пакетов отбито,
   forced-egress в full rc=7, в smart/off открыт (там fail-closed и не заявлен).

## Цифры после (живая матрица)
- toggle full 14с → 4с; full→smart 4с с 1-го опроса; smart↔proxy 2–3с.
- status-json в покое 0.75с (был 2.6с).
- 22/22 pytest хост; GUI redeploy + рестарт; PUSH.
