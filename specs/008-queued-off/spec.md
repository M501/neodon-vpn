# Spec 008 — проглоченное выключение (flow-track)

## Жалоба
proxy→tunnel, сразу кнопка off: гаснет и тут же загорается, таймер идёт.
«Выключение не сработало».

## Доказательство
- Таймер шёл = эпоха не чистилась = `set_state` не покидал CONNECTED =
  `toggle("off")` не стартовал вовсе.
- transitions.log: после CONNECTED/full тишина, OFF нет. Нажатие проглочено
  флагом `_op_in_progress` (тоггл туннеля ещё летел 4–9с), виден был лишь
  statusBar-текст. Погасание/возврат кнопки — обычные опросы перехода.

## Фикс (одна воронка)
- `_request_op(kind, *args)`: свободен — выполнить, занят — запомнить
  last-wins + «поставлю в очередь…». Сюда завернуты питание, смена режима,
  оба пути смены сервера. Прерывать полуразобранный firewall нельзя —
  только очередь, не cancel.
- `_drain_pending()` в обоих done-хендлерах.

## Verify
27/27 pytest (queue+drain+last-wins) → деплой → рестарт → backend
не тронут (full CONNECTED как был) → CHANGES + push.
