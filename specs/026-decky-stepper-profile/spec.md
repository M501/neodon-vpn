# Spec 026 — Decky: степпер серверов + строка профиля (flow-track)

## Проблема
- Нативный Dropdown серверов не стрелял onChange (в WS-логе ни одного
  set_server при попытках владельца). Режимный Dropdown (2 статики)
  работал — разница в динамике/эмодзи-лейблах, точную причину внутри
  стимовского BuildMenu не доказать без CEF-дебага.
- Не видно, какой traffic-профиль активен в игровом режиме.

## Решение
- Степпер «◀ / ▶» + «лейбл (i/N)» — только наш код, геймпад-френдли.
- Строка «Профиль: X (как в десктопе)» из status-json.profile.
- Бэкенд set_server не тронут (полный: 3 конфига + рестарт + киллсвитч).
- Архитектура подтверждена: игровой режим — тонкая обёртка над ТЕМИ ЖЕ
  скриптами/профилями, наследование traffic rules автоматическое.

## Пруфы
- test_bundle.mjs зелёный (static/default/shape/connect/call).
- DIST 200:9752, backend up, журнал чист.
