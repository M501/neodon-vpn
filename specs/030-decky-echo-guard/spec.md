# Spec 030 — Decky echo guard: тумблер не довызывает сам (flow-track)

## Баг
- Вкл → выкл за 1-2с в QAM: выкл не срабатывал, тумблер загорался снова.
- Доказательство: webhelper `vpn_down 20:36:47` → `vpn_up 20:36:49`, 2с,
  без нажатия. Механика: опрос/refresh через 1.2с видел ещё-CONNECTED,
  `checked` флипался назад, Steam перевызывал onChange(true) → vpn_up.
- Десктопная кнопка — обычная кнопка без checked-эха, там этот класс
  невозможен; десктопный фикс намерения (029/52) в силе отдельно.

## Фикс (только фронт панели)
- `seenRef` (последняя отрисованная позиция) + `wantRef` (последняя
  команда с меткой): onChange с v == seen — эхо, в бэкенд не идёт.
- Quiet window 8с: пока своя команда летит, опрос не дёргает checked.
- Каждое настоящее переключение срабатывает ровно один раз; эхи — ноль.

## Пруфы
- test_bundle.mjs: static-echo-guard (seenRef/wantRef/условие в бандле).
- Harness зелёный, деплой, backend up, журнал чист.
- Живой пруф — глаза владельца: вкл→выкл за секунду, без переподсвета.
