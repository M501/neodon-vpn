## 2. PROBLEM & PURPOSE

### Problem Statement
Владелец после правки 038: (1) «если быстро тыкать серверы — начинается странная залупа, выделение прыгает между серверами»; (2) «у одного сервера нет флага — кажется, немецкого»; (3) «посмотри, что там ещё есть, найди всё и поправь всё — продакшн реди».

**Корневые причины (все измерены на устройстве, не гипотезы):**
1. **Три писателя в одно поле выбора** (`selected_tag`/`selected_addr`): оптимистичный тап, чтение `selected-server.json` после операции и полл `status-json` — без правила очерёдности. При быстрых тапах: тап A → A, тап B → B (в очередь), завершение A читает файл (там ещё A) → подсветка прыгает на A, потом B, а «протухший» полл, запущенный до операции, мог вернуть A и снова перекрасить карточку.
2. **`render_servers()` пересобирал всю сетку на каждое изменение выбора** (`deleteLater()` + новые виджеты) — лишняя работа и уничтожение виджета под пальцем.
3. **Qt отдаёт нажатие второго быстрого тапа в QWindow, а не в виджет** (замер спаем: `MouseButtonPress` и `MouseButtonDblClick` → QWindow, `TouchBegin` → viewport, карточке приходит только `release` без нажатия). До 038 это «работало» именно через ветку «отпуск без нажатия = тап», из-за которой прокрутка списка выбирала сервер; в 038 ветка была закрыта — и быстрый второй тап перестал срабатывать вовсе.
4. **`flags/DE.png` в наборе отсутствует.** Флаги в репозитории — это байт-в-байт `flagcdn.com/w40/<iso2>.png` (AT/RU/NL/US/EE совпали по sha256), для Германии файл просто не положили → `flag_pixmap()` вернул None → серая точка. Провайдер использует и нестандартные коды (`[SW]` для Швеции), поэтому флаг ищется по коду из подписи.
5. Прочее по итогам аудита (см. раздел 6) — перечень подтверждённых дефектов и решений.

### Purpose
Быстрое переключение серверов в десктоп-GUI работает на любой скорости без «прыжков» выделения и без ложных выборов от жестов; все страны подписки показываются с флагом; подтверждённые аудитом дефекты закрыты.

## 3. SCOPE

### In Scope
- Подсветка выбора: один владелец состояния (интент пользователя) + перерисовка на месте без пересборки сетки.
- Тап-логика: корректный второй быстрый тап (Qt DblClick в QWindow) при сохранении запрета на выбор сервера жестами.
- Флаги: `flags/DE.png` из того же источника-набора; информативный фолбэк вместо пустой точки.
- Аудит десктоп-GUI, control-plane скриптов и Decky-панели (три независимых ревьюера) → фиксы подтверждённых дефектов.

### Out of Scope
- Бэкенд-модель (selector/Clash API) и режимы VPN — не меняются, только подтверждённые дефекты.
- Редизайн UI, новые экраны, изменение вёрстки за пределами найденных дефектов.
- Автоподключение при выборе сервера — по-прежнему запрещено (power только тумблером).

## 6. RISKS & DEPENDENCIES

| Type | Item | Impact | Mitigation |
|------|------|--------|------------|
| Dependency | Clash API `127.0.0.1:9090` | при OFF недоступен | `curl -m 1`; отсутствие API = нет метки живой ноды |
| Dependency | `selected-server.json` | нет файла | пустой выбор = нет подсветки |

## L2: EDGE CASES

| Case | Expected behavior | Verified |
|------|-------------------|----------|
| Два тапа по разным серверам с гэпом 150 мс | выбирается второй, подсветка не возвращается | да (4 кадра бурста) |
| Два тапа с гэпом 250 мс | то же | да |

| Прокрутка списка пальцем | выбора нет, прокрутка работает | да |
| Горизонтальный свайп | контент не двигается, выбора нет | да |
| Смена сервера из Decky-панели | подсветка переезжает в пределах полла | да |
| Нет файла флага для страны | показывается код страны | да (DE до добавления ассета) |
| Два refresh подписки подряд | второй отклоняется, `raw.json` не портится | по коду + флаг `_sub_busy` |
