# GUI checklist — прогон по живому интерфейсу (адаптировано под Qt/Wayland/тач)

## Interruptions (ронять посреди операции)
- [ ] kill GUI mid-toggle → бэкенд доходит сам, рестарт GUI показывает правду.
- [ ] Обрыв сети mid-connect → TRANSITIONING→DEGRADED, без вечного виса.
- [ ] systemctl stop сервиса вручную → FAILED/LOCKED честно, не CONNECTED.

## Тач (пойманные баги — регрессия поименно)
- [ ] Отпуск после скролла ≠ тап (slop 12px, QTest обе стороны).
- [ ] Двойной тап по питанию в settle-окне не включает обратно.
- [ ] Тап по карточке сервера/пресета срабатывает с 1-го раза.

## Подсветка и пилюля
- [ ] Свитч full→smart: подсветка не возвращается на TUNNEL mid-toggle.
- [ ] Пилюля показывает Switching… весь переход (маркер жив до CONNECTED).
- [ ] Уведомление «Подключено» один раз и по факту, не в момент нажатия.
- [ ] Таймер не сбрасывается на 1–2 миганиях (гистерезис 3).

## Трафик-правила (не бутафория)
- [ ] У каждого пресета видны counts (сколько доменов куда) + footer куда остальное.
- [ ] Бейдж «подтверждено» = аудит пройден (audit_parity + живые пробы), иначе «не подтверждено».
- [ ] Активный пресет = реально применённый конфиг (checksum/профиль в status-json).

## Конфигурации
- [ ] Тёмная тема, HiDPI-масштаб, ресайз окна (620–720px), перезапуск (состояние восстанавливается).
